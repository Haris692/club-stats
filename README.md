# Statistiques de match pour les clubs — démonstration

Site de démonstration d'un outil de statistiques pour les clubs de football :
à partir des exports XML du fournisseur de données (InStat), un site privé par
club, en arabe, en anglais et en français.

- **Données inventées** : les clubs, les joueurs et les matchs de la démo sont
  fictifs.
- **Essai avec vos fichiers** : les fichiers déposés sont analysés dans le
  navigateur (Python compilé pour le web, [Pyodide](https://pyodide.org)) et ne
  sont envoyés nulle part.

---

*Match statistics for clubs — demo. A private site per club built from the
data provider's XML exports, in Arabic, English and French. The demo league is
made up; files you drop are analysed in your browser and never uploaded.*
